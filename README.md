# Dataset used for model training
Binary: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
Multi-class: https://www.kaggle.com/datasets/tawsifurrahman/covid19-radiography-database

# How to run the application
## Create VENV on version 3.11 of python
py -3.11 -m venv myenv

## Activate VENV
.\myenv\Scripts\activate

## Run app
py -m app.app
